## TYPOGRAPHY
Display Font:  'Bebas Neue' — ALL CAPS headings, hero text, section titles
Body Font:     'DM Sans' — body text, labels, buttons, UI elements
Serif Accent:  Georgia — logo wordmark ONLY (SOLID/BAY lettering)

## LOGO
The logo consists of:
- Building icon (green towers with gold peak/roof accent)
- "SOLID" in gold (Georgia serif, bold)
- "BAY" in green (Georgia serif, bold)
- Divider line + "CONSTRUCTION / SAN FRANCISCO / EST. 2016" tagline

## DESIGN PRINCIPLES
- Light/cream background (NOT dark) — matches logo light version
- Mobile-first responsive design
- Tailwind CSS via CDN for consistent spacing
- Smooth reveal animations on scroll
- Card hover: translateY(-4px) with green border
- Section tags: uppercase, letter-spaced, green with line prefix
- Section dividers: 48px wide, 2px tall, gold (#C9A84C)

## SEO RULES
- H1: One per page, descriptive, includes location
- H2: Section headings, include "San Francisco" or "Marin County" where natural
- H3: Card/FAQ titles, answer specific user questions
- Schema: GeneralContractor + FAQPage JSON-LD on all pages
- Meta description: Under 160 characters, include location
- Alt text: Describe image content + location context

## CONTENT VOICE
- Professional but approachable
- Confident — we are experts, not salespeople
- Location-specific — always mention SF and/or Marin County
- Specific numbers — "100+ projects", "10 years", "7 experts"
- No fluff — every sentence earns its place

## DO NOT USE
- Dark backgrounds on main site (reserved for process section only)
- Purple gradients or generic AI color schemes
- Generic fonts (Inter, Roboto, Arial as primary)
- Oakland or East Bay references
- North Bay references (only SF and Marin County)
- Testimonials (not yet available)
- Placeholder phone/email (show "Coming soon")
